**整理、起草、签署，全程不离开对话。** DaySurface 把一个按优先级排序的收件箱和一个
真实的邮件撰写器放进 Claude、ChatGPT 或你惯用的智能体里。智能体负责整理和撰写，
你负责编辑和发送。

它通过流式 HTTP 连接，因此无需安装任何东西：在客户端里添加一个 URL，
再授权一次 Gmail 访问即可。

## 隐私

我们绝不会把你的邮件发送给 AI 模型。DaySurface 不对 Gmail 内容运行任何 LLM 推理，
收件箱排序是确定性代码。邮件只会传给你自己连接的 AI 客户端，并遵循该客户端自身的
条款。访问使用 Google 的 `gmail.modify` 权限范围：可以读取、加标签、起草和发送，
但无法永久删除你的邮件。
