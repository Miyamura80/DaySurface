The MCP server is how DaySurface gets into your chat. Once connected, your
assistant can rank your inbox, read threads, draft and send replies in a real
composer, and fill and sign PDF attachments - 34 tools, all through the official
Gmail API.

**Remote (recommended)** clients connect to the deployed **streamable-HTTP**
endpoint at `/mcp` - nothing to install, one URL to add. **Local stdio** is
supported for development against a checkout.

```
https://mcp.daysurface.com/mcp
```

## Quick Start

1. [Set up your client](/docs/mcp/setup) - most install in one click; a few take a pasted URL or command
2. Connect Gmail with `gmail_connect` and approve the Google sign-in
3. Ask for what you want: _"what needs my attention today?"_

## Interactive apps

Some tools render an MCP App - a sandboxed iframe UI - in clients that support
it: the ranked inbox dashboard, the draft composer, the PDF signing surface, and
the settings panel. In clients that do not, the same tools return plain
structured output, so nothing breaks. The [tool reference](/docs/mcp/tools)
marks which ones have a UI.
