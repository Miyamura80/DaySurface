title: DaySurface - un servidor MCP para Gmail
description: Conecta Gmail con Claude, ChatGPT o cualquier cliente MCP. Prioriza tu bandeja, redacta respuestas y rellena y firma archivos PDF adjuntos.
---

DaySurface es un servidor MCP que pone tu bandeja de Gmail dentro de tu cliente de IA.
Ofrece tres formas de interactuar con el mismo conjunto de herramientas:

- **CLI** - Ejecuta comandos en tu terminal
- **MCP** - Conecta asistentes de IA como Claude directamente
- **REST API** - Llama a endpoints por HTTP con autenticacion

Elige la interfaz que mejor se adapte a tu flujo de trabajo, o usa las tres.

## Instalacion

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Instalar desde el codigo fuente

```bash
git clone https://github.com/Miyamura80/DaySurface.git
cd DaySurface
uv sync
```

</Step>
<Step>

### Verificar la instalacion

```bash
uv run daysurface --version
uv run daysurface --help
```

</Step>
<Step>

### Probar un comando

```bash
uv run daysurface greet Alice
# Hello, Alice!
```

</Step>
</Steps>
